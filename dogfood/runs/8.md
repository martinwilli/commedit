# Run 8 — 2026-06-29 (k=1 full grid; `feature/plugin-skill-tune` regression check)

A **k=1** smoke/regression run of the full grid — **12 tasks × 3 solvers = 36 students** — to confirm
the `feature/plugin-skill-tune` skill+operator changes (reframed skill descriptions to prefer commedit
over fiddly git, closed coverage gaps for uncommit / merge-editing, session-aware footers, the session
selector noted in the last two skills) did **not regress** operator ergonomics or tool routing. First
run to include **T12** (content-blame squash target), which run 7 predated.

**MCP surface under test:** the installed plugin snapshot
(`~/.claude/plugins/cache/commedit-local/commedit/0.5.0`) was verified **byte-identical** to the
working tree (`diff -rq` over `skills/`, `agents/`, `bin/` — all clean), so the tuned skills + operator
are exactly what the students loaded. MCP binary freshly built today (mtime 22:30). The skill-tuning
branch touches no engine code, so the MCP *tool surface* is unchanged from run 7; what's under test is
the **skills + operator prompt**. Teacher on Opus; students on Sonnet 4.6 per protocol. All 36 students
were independent cold spawns; the three solvers of a task ran concurrently (distinct sessions / no
session for git), peak ~36-way ref-write exposure.

## Result: 36/36 oracle-PASS, **zero ref-race reverts** (post-settle re-check clean)

Every cell passed `verify.sh` on first completion **and** on the mandatory post-settle re-check across
all 36 worktrees — no silent revert at full concurrency (the run-7 `c6f56ca` backstop-scoping fix holds
with the `gc.auto` mitigation still rolled back). **The skill-tuning branch introduced no regression:**
all 24 MCP students (op+ctl) routed to the right tool on every task, including the new T12
content-blame path (`blame_squash_targets`, not the dead-end `suggest_squash_targets`).

## Headline findings

1. **No regression; the operator is markedly the cheapest solver this run.** Per-class totals over 12
   students each: **op $3.12 · ctl $6.70 · git $7.09** (grid ≈ **$16.9**). Per-cell median **op $0.246 ·
   ctl $0.506 · git $0.573**. This is a *wider* op↔ctl gap than run 7's wash ($0.30 vs $0.31) — driven
   by the operator reaching the end state in far fewer calls (median **6** vs ctl **14**, git **16**)
   with near-zero per-turn input (skills point it straight at the tool; no `ToolSearch` discovery tax
   the control re-pays). **k=1 caveat:** single sample per cell, so this is a directional aggregate
   signal over 12 cells, *not* a per-cell rank claim (the variance protocol still wants k≥3 to rank
   close cells).
2. **`cherry_pick_commit` rejects a short sha for an off-branch commit (T11, both op and ctl).** The
   commit being moved lives on the *feature* sibling, unreachable from the *trunk* session's HEAD, so a
   short sha didn't resolve — the call failed and both students recovered by fetching the full 40-char
   sha via read-only `git log` and retrying. They recovered gracefully, but it's a real ergonomic snag
   on the multi-tenant path: cross-session cherry-picks want the full sha. Candidate fix — accept/resolve
   a short sha for an off-branch source, or have the error name the full sha.
3. **T9 is the clearest MCP-value task this run.** The operator re-dated + re-identified the 3-commit
   range in a **single `edit_commits` batch (2 tool calls, $0.13, 21s)**. The plain-git student's
   interactive rebase **re-stamped all 9 descendants' committer identity** to the worktree's git config
   and it had to detect and repair that with a `filter-branch --env-filter` (18 calls, $0.71, 167s) — the
   exact "scoped metadata edit shouldn't touch unrelated commits" trap the atomic batch avoids.
4. **Leftover `rerere` cache flatters the git baseline on conflict tasks — now mitigated.** `rerere.enabled`
   is on in this repo and its cache lives in the **shared git common dir**; teardown never cleared it, so a
   prior run's hand-resolved T3/T10 conflicts were **auto-applied to the git student on its first conflict
   encounter** (t3-git rode it). Tellingly, **t10-git noticed and passed `-c rerere.enabled=false`** so its
   resolve was genuinely by hand. Doesn't change end state (oracle still grades correctly) but inflates the
   git baseline's apparent conflict-task ease. Fixed: teardown now `rm -rf …/rr-cache` (README §6).
5. **Discriminators all held.** T2 split footgun stayed closed (op+ctl both listed `util.txt` at *parent*
   content → fix moved to the child). T6 untracked `backup.txt` was tracked by all three (add_paths). T7
   merge kept its 2 parents under reword+fixup. T10 abort beat fired (held rewrite → `abort_rewrite` → git
   frozen, then resolve to 256). T11 off-worktree sibling session opened cleanly. T12 content-blame
   returned the single `Add retry helper` candidate as designed.
6. **git is ~3× the operator's wall-clock** (median 143s vs 46s), tail dominated by `--rebase-merges` and
   scripted sequence-editor tasks: t1-git 307s, t5-git 249s (both hit the "rebase base is not a `pick`
   line" gotcha — one no-op replay before injecting the pick after `reset onto`), t6-git 179s, t9-git 167s.

## What this run establishes / known gaps

- **The skill-tuning branch is safe to land.** All 36 cells pass; the tuned operator + skills routed
  correctly on every task including the new T12 content-blame path. No tool-routing regression.
- **k=1 is a regression smoke test, not a ranking run.** The op↔ctl cost gap looks larger than run 7's,
  but per-cell that's one dice roll; a *comparative* claim (does the skill tuning make the operator
  cheaper?) needs **k≥3** with median+spread (variance protocol, §5). What k=1 *does* establish: nothing
  broke, and zero ref-race reverts at 36-way exposure.
- **Two follow-ups for the MCP surface:** (a) `cherry_pick_commit` short-sha rejection for off-branch
  sources (finding 2) — minor, recoverable, but a multi-tenant ergonomic snag worth smoothing; (b) the
  `rerere` cache cleanup is now in teardown (finding 4) — keep it there.
- **The oracle remains mandatory and authoritative.** Re-run after settle every time; this run's
  post-settle pass on all 36 is the evidence the race stays fixed with the mitigation rolled back.
